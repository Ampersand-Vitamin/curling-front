01Overview

Curling은 곱슬머리·외국인·특수 헤어타입을 가진 사람들이 자기 머리를 진짜로 이해하는 디자이너를 스타일 검색으로 찾아 바로 연결되는 모바일 플랫폼이다.

Product Goal

카카오헤어샵·네이버예약이 점령한 직모 중심 시장 바깥에 남겨진 곱슬·특수머리 사용자들에게, "내 헤어 타입을 이해하는 디자이너를 스타일로 검색해서 직접 연결"하는 경험을 제공한다. 동시에 곱슬·특수 시술 전문 디자이너에게 본인 포트폴리오를 자산화하고 이상적 클라이언트를 끌어들이는 전용 플랫폼이 된다.

Background

한국 인구의 15–20%(Type 3)와 한국 거주·방문 외국인(Type 3–4 비중 높음)은 "내 곱슬을 다룰 줄 아는 디자이너"를 찾기 위해 인스타 해시태그를 손수 뒤지거나 레딧의 산재된 추천 글에 의존한다. 기존 booking 플랫폼은 직모 기반 검색만 지원하고, 소셜 미디어는 검색이 아닌 알고리즘 노출에 의존한다. 이 공백이 Curling의 시장이다.

02Core Value

User Problem

곱슬·특수머리 클라이언트는 일반 미용실에서 "내 머리를 못 다룸"을 반복 경험하고, 시술 실패와 신뢰 비용을 지속적으로 부담한다. 곱슬·특수 전문 디자이너는 demand는 있지만, 인스타 알고리즘에 의존하는 산발적 노출과 부재한 포트폴리오 관리 도구로 수요-공급 매칭에 실패한다.

Solution

Pinterest처럼 작동하는 Style 탭이 핵심. 자연어 + 키워드 + 헤어타입 인덱싱 기반으로 스타일을 검색하고, 각 스타일은 시술한 디자이너에게 1:1로 연결된다. DM으로 즉시 상담 가능. Discover(지도)는 위치 확인용 보조 탭, My 탭에서 헤어 프로필과 저장한 스타일을 관리한다.

Differentiator (vs 카카오헤어샵·네이버예약·인스타)

  • 헤어타입 × 시술 × 길이 × 스타일링 4축 인덱싱 — 곱슬·특수에 특화
  • 자연어 검색 — "C컬 곱슬 단발", "korean perm for foreigners" 같은 의도 기반 쿼리
  • 다국어 지원 (KR / EN) — 외국인 비치헤드 직접 공략
  • 예약 수수료 0% — 구독 + 광고 모델로 디자이너 부담 해소
  • Style → Designer 1:1 매핑 — Pinterest엔 없는, 영감과 실행의 직결

03Beachhead (v1 Scope)

v1은 단일 비치헤드에 집중한다. 범용 헤어 매칭 플랫폼을 만들지 않는다 — 만들면 카카오헤어샵에 진다.

✓ IN — v1 타겟
  • Client: Type 3 (Curly) 한국 거주자
  • Client: 한국 거주·방문 외국인 (Type 3–4 비중 높음)
  • Designer: D1 — 곱슬·특수 시술 전문, 1–5년차, 프리랜서·공유미용실
  • Geography: 홍대 · 성수 · 강남 · 이태원 · 한남
✗ OUT — v1 의도적 제외 (anti-personas)
  • Type 1–2 직모 클라이언트 → Red Ocean, 카카오·네이버 점령
  • 체인 살롱 (준오·박준·이가자) → 영업주기 6–12개월
  • D2 일반 트렌드 디자이너 → Phase 2 확장
  • 예약·결제 기능 → Phase 3 (먼저 매칭 가치 증명)
왜 anti-persona를 명시하나: 팀이 "그래도 직모 유저도 잡아야지" 하는 유혹에 빠지지 않도록 PRD가 차단한다. 확장은 비치헤드 정복 후 Curly → Coily → Wavy → Straight 순서.

04Target Users & Personas

Designer · D1

곱슬·외국인 전문 디자이너

  • 1–5년차 프리랜서·공유미용실, 인스타 팔로워 5k–30k
  • 곱슬 시술 단가 일반 대비 1.5–2배, 시술 3–5시간 → 노쇼 치명적
  • 이미 인스타에 포트폴리오를 올리지만 검색 안 됨 · 자산화 안 됨
  • 가치 제안: "포트폴리오 퍼뜨리기는 무조건 이득" — Pinterest 메타포에 즉시 동기화
Client · Type 3 + Foreigner

곱슬머리 보유자 · 외국인

  • 일반 미용실에서 "내 곱슬 못 다룸" 반복 경험
  • 한국 거주·방문 외국인, 헤어 실패 경험 보유
  • 인스타 해시태그(#곱슬머리펌, #C컬펌)와 레딧 추천 글로 디자이너를 손수 찾는 패턴
  • 사례·리뷰·비포애프터 강한 신뢰 → 한 번 좋은 디자이너 찾으면 LTV 매우 높음

User Roles (Feature spec 연결용)

  • Client: Type 3 Curly · Type 4 Coily · Foreigner · Type 1–2 [Phase 2]
  • Designer: D1 Curly Specialist · D2 Trend Stylist [Phase 2] · D3 General [Phase 3]

05Usage Scenario

핵심 펀넬: Style 검색 → Designer 포트폴리오 → DM. Discover(지도)는 위치 확인용 보조.

1 Sarah는 한국 거주 외국인. 자기 곱슬머리를 다룰 줄 아는 디자이너를 찾고 있다. Curling을 열고 Style 탭에서 "C-curl perm short curly"를 검색한다.

2 자기 헤어타입과 매칭된 실제 시술 포트폴리오들이 Pinterest처럼 나열된다. 마음에 드는 스타일을 탭하면 그 시술을 한 디자이너의 전체 포트폴리오로 이동.

3 같은 헤어타입의 다른 사례·비포애프터·리뷰를 확인한 뒤 Message 탭에서 저장한 스타일을 레퍼런스로 첨부해 DM을 보낸다.

4 상담 확정 후 Discover 지도로 살롱 위치를 확인, My 탭에서 헤어 프로필·저장 스타일·예약 이력을 관리한다.

07Go-to-Market

고객이 모여 있는 곳 (우선순위)

  • 1

    인스타그램

    디자이너 포트폴리오 관리의 default. 클라이언트는 인스타에서 스타일을 서치하고 DM으로 예약까지 진행 — 우리의 펀넬과 정확히 같은 형태.
  • 2

    레딧 — 외국인 채널

    r/korea · r/seoul · r/livinginkorea에 "Where can I get a haircut in Seoul for curly hair?" 류 글이 정기적으로 올라온다. 신뢰도 떨어지는 산재 정보 — 우리가 채울 공백.
  • 3

    공유 미용실 운영사

    살롱드핏 · 헤어셀럽 · 챕터원. B2B 파트너십 한 번에 디자이너 수십 명 확보 가능 — 효율 최고 채널.
  • 4

    SEO · 헤어 블로그

    "곱슬머리 C컬펌", "외국인 미용실 서울" 같은 long-tail 검색어를 콘텐츠로 점령.

데려오는 방법 — 단계별

디자이너 풀 먼저 확보

인스타 DM + 직접 방문으로 곱슬·외국인 전문 디자이너 컨택. 공유 미용실 1–2곳 파트너십.

제안 — 검색 탭 상단 슬롯 무료 보장

"오픈 전에 들어오면 본인 Speciality 전문 키워드에 대해 Style 탭 검색 결과 상단을 보장. 가입비 0원, 광고비 0원."
핵심 정교화: "상단 노출"은 가입자가 늘수록 인플레이션됨. 키워드 단위로 좁혀 보장한다 — "곱슬 C컬펌 키워드 상단 1자리, 6개월, Founding 100명 한정". 이렇게 키워드를 슬롯 인벤토리화하면 v3 Boost 광고 가격의 근거가 된다.

그럼 유저는?

  • 커뮤니티 침투 — 레딧·헤어 카페에서 실제 유저 페르소나로 우리 서비스 추천
  • 페이드 마케팅 — 스토리텔링 광고
    • "미용실에서 머리 실패 → Curling으로 원하는 스타일 검색 → 그 스타일 기반 상담 → 만족"
유저는 이미 확보한 디자이너 풀 덕에 Style 탭 검색에서 즉시 가치를 느낀다 — supply가 demand를 끌어당기는 구조.

SEO 점령

각종 헤어 스타일 관련 블로그·포트폴리오 페이지가 long-tail 검색어를 자동 흡수 — 시간이 지날수록 CAC가 0에 수렴.

09Risk & Mitigation

  • Cold Start (Chicken-and-Egg)
    디자이너 없이는 클라이언트 안 오고, 그 반대도 성립. 양면 시장의 고전적 함정.
    완화: Phase 1에서 디자이너 supply를 먼저 100명 확보 → 콘텐츠 채워진 상태로 demand 유입 시작.
  • Founding 100 Slot Inflation
    "상단 노출" 약속이 가입자 늘수록 자동 희석. 100명 다 1번일 수 없음.
    완화: 노출 약속을 키워드 단위 슬롯으로 좁혀 인벤토리화. v3 Boost 광고 가격 근거로 재활용.
  • 비치헤드 자원 분산 (한국인 곱슬 vs 외국인)
    두 페르소나를 동시에 잡으려다 둘 다 놓치는 리스크.
    완화: v1 전반 한국인 곱슬, v1 후반 외국인 확장. 다국어 지원은 v1 후반 마일스톤으로 분리.
  • 디자이너 6개월 이탈
    클라이언트 유입이 늦으면 디자이너가 떠나 콘텐츠 자산 손실.
    완화: Founding 첫 30일 내 디자이너당 DM 1건 이상 목표. SEO + 페이드 광고로 demand 초기 인공 가속.
  • 기존 booking 플랫폼 경쟁 (카카오·네이버)
    그들이 곱슬 카테고리를 모방해 들어올 가능성.
    완화: "0% 수수료" + 헤어타입 인덱싱 + 외국인 시장 — 3중 해자. 그들이 들어오기엔 수익 모델 충돌.
