Discover vs Style — 탭 역할 & 필터 설계

2026-04-18 · 팀 논의용

Abstract

1. Discover 탭의 필터 팝업 키워드와 실제 디자이너 데이터가 일치하지 않고, 검색 필터와 고객 프로필이 혼재되어 있다.
2. Discover와 Style 두 탭이 모두 "디자이너 찾기"를 하는데, 기능 경계가 정의되지 않았다.
3. 이 문서는 탭 역할 분리와 필터 구조 개편 방향을 논의하기 위해 작성되었다.

1 두 탭의 역할을 명확히 정의해야 한다

Discover와 Style 모두 "디자이너/살롱 찾기"를 한다. 하지만 찾는 방식이 근본적으로 다르다.

2 현재 문제: FilterPopup이 안 맞는다

키워드 불일치 + 성격 혼재

하드코딩된 60+ 키워드가 실제 데이터와 안 맞고, 검색 필터와 고객 프로필 정보가 섞여있다.

데이터 불일치

FilterPopup에 없는 실제 서비스:

Braids Balayage Curly Cut Locs Fade Keratin

FilterPopup에만 있고 데이터에 없음:

Down Perm Wig Root Touch-up

성격 혼재

검색 필터 (디자이너 속성):

Service Language Hair Type

고객 프로필 (필터가 아님):

Hair Color Hair Length Treatment History Hair Concern
즉, 필터 팝업 키워드 = 디자이너/살롱 키워드 → 같은 계층에서 관리
Discover는 유사도 검색이 아닌 정확한 1:1 매칭이다. 유저가 "Balayage"를 선택하면 DesignerKeyword에 "Balayage"가 있는 디자이너만 나와야 한다. 이를 위해 필터 키워드와 디자이너/살롱 키워드는 반드시 동일한 Keyword 테이블에서 관리되어야 하며, 별도로 관리하면 불일치가 반복된다.
"Blonde"를 선택하는 건 "Blonde 전문 살롱"이 아니라 "내가 Blonde"라는 뜻.
이건 검색 필터가 아니라 프로필 정보 → My 탭의 Hair Profile에서 관리.

4 Profile 연동 문제

Discover에 Profile을 직접 연동하면 "정확 매칭"이 깨진다

고객 Profile: "Damaged" (내 머리 상태)
디자이너 Keyword: "Damaged Hair" (다뤄본 경험)

→ 고객은 상태를 말하고, 디자이너는 능력을 말한다.
→ 이걸 매칭하려면 매핑 레이어 필요 → 정성적 검색 영역 → Style 탭의 역할
고객 Profile정확 매칭?문제
hair_type: Curly✓ 가능Hair Type 필터 "Curly" = DesignerKeyword "Curly"
length: Medium—길이는 디자이너 능력과 무관
concern: Damaged✗매핑 레이어 필요 → 유사도 영역
color: Blonde✗디자이너 키워드에 색상 경험 없음
history: Bleached✗매핑 레이어 필요 → 유사도 영역

직접 매칭 가능한 건 Hair Type뿐. 나머지는 정성적 검색(Style 탭)이 필요.

5 제안: Recommended 키워드를 Profile 기반으로 동적 생성

Profile을 필터에 직접 연동하지 않고, Recommended 키워드로 간접 반영한다.

Discover의 정확 매칭은 유지하면서, Profile이 자연스럽게 녹아드는 방식.

작동 방식

내 프로필: Curly, Medium, Damaged, English

↓ Recommended Keywords 자동 생성
English Speaker Curly Hair Expert Damaged Hair Care Foreigner Friendly
  • Profile 기반으로 추천할 뿐, 자동 적용하지 않음
  • 유저가 직접 선택/해제 가능 (강제가 아님)
  • 선택하면 기존 정확 매칭 로직 그대로 동작
  • Profile이 없으면 인기순 Recommended 표시

장점

✓Discover의 정확 매칭 원칙이 깨지지 않음
✓Profile이 자연스럽게 반영됨 (키워드 추천)
✓키워드 계층 문제 없음 (추천일 뿐 매칭은 동일)
✓Style 탭과 역할 구분 유지

8 결론!

핵심 결정

  • Discover = 정량 필터 / Style = 정성 검색 — 이렇게 역할 명확히 분리?
  • 고객 프로필(Hair Color, Length, Concern 등)은 필터에서 빼고 My 탭으로 — Discover 필터에는 직접 연동하지 않고 Recommended 키워드 추천으로 간접 반영? 확정 시 필터 팝업 UI 디자인 개선 필요
