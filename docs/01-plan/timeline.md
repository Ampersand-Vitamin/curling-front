# AI 디자이너 매칭 — 타임라인

## 전제

- 방식: Vision AI 태깅 (MVP) → 자체 데이터 파인튜닝 (v2)
- 태그 체계: K-Hairstyle 기반
- 인프라: Supabase (PostgreSQL) + Next.js API Routes
- 1인 개발 기준 (풀타임이 아닌 경우 ×1.5~2)

## Phase 1: MVP 완성 (2주)

> 목표: 실제로 동작하는 데모를 만들어서 보여줄 수 있는 상태

### Week 1: 백엔드

| 일 | 할 일 |
|---|---|
| Day 1 | Hugging Face 토큰 발급 + /api/search에 HF CLIP 연동 테스트 |
| Day 2 | /api/analyze 태깅 API 구현 (Vision AI + K-Hairstyle 태그 체계) |
| Day 3 | /api/match 태그 매칭 API 구현 (가중치 + mustMatch) |
| Day 4 | Supabase Storage에 포트폴리오 이미지 업로드 파이프라인 |
| Day 5 | 데모 디자이너 데이터 보강 (프로필 이미지, 상세 정보) |

### Week 2: 프론트엔드 + 연동

| 일 | 할 일 |
|---|---|
| Day 6 | 이미지 업로드 UI 완성 (드래그앤드롭, 미리보기, 에러 처리) |

### 산출물

- `/discover/ai-match` 페이지 동작
- 이미지 업로드 → 태그 분석 → 디자이너 매칭 전체 플로우
- 데모용 디자이너 10명 + 포트폴리오 30장

## Phase 2: 실서비스 준비 (3주)

> 목표: 실제 디자이너가 가입하고, 실제 유저가 쓸 수 있는 상태

### Week 3: 디자이너 온보딩

| 할 일 | 설명 |
|---|---|
| 디자이너 가입/로그인 | Supabase Auth |
| 포트폴리오 업로드 UI | 디자이너가 직접 이미지 올리기 |
| 업로드 시 자동 태깅 | Vision AI로 포트폴리오 태그 자동 생성 |
| 디자이너 프로필 편집 | 이름, 소개, 전문 분야, 언어 |

### Week 4: 유저 경험 개선

| 할 일 | 설명 |
|---|---|
| 검색 결과 필터 | 태그 기반 필터바 (길이, 색상, 스타일 등) |
| 검색 히스토리 | 이전 검색 결과 다시 보기 |
| 디자이너 상세 페이지 | 포트폴리오 갤러리 + 프로필 |
| 반응형 UI | 모바일 최적화 |

### Week 5: 안정화 + 배포

| 할 일 | 설명 |
|---|---|
| 에러 처리 강화 | API 실패, 타임아웃, 이미지 형식 검증 |
| 로딩 UX | 스켈레톤, 프로그레스바 |
| Vercel 배포 | 환경변수 세팅, 도메인 연결 |
| 모니터링 | API 비용 추적, 에러 로깅 |

### 산출물

- 디자이너 가입 + 포트폴리오 관리 가능
- 유저가 이미지 업로드로 매칭 가능
- 프로덕션 배포 완료

## Phase 3: 데이터 축적 + 개선 (1~3개월)

> 목표: 파인튜닝 전환을 위한 데이터 축적 + 서비스 품질 개선

| 기간 | 할 일 | 목표 |
|---|---|---|
| 1개월 | 유저 피드백 수집 + 태그 정확도 모니터링 | 문제점 파악 |
| 1개월 | 태그 체계 조정 (실사용 기반) | 불필요한 태그 제거, 누락 태그 추가 |
| 1~3개월 | 태깅 데이터 축적 | 목표: 5,000~10,000장 |

### 이 기간에 자동으로 쌓이는 것

```
유저 업로드 → Vision AI 태깅 → (이미지, 태그) 쌍 저장
디자이너 포트폴리오 업로드 → 자동 태깅 → (이미지, 태그) 쌍 저장
```

---

## Phase 4: 파인튜닝 전환 (2주)

> 전환 시점: 태깅된 이미지 10,000장 이상 축적 시

### Week 1: 모델 학습

| 할 일 | 설명 |
|---|---|
| 학습 데이터 정제 | 오태깅 제거, 불균형 카테고리 보강 |
| ViT 파인튜닝 | Google Colab에서 학습 (Hugging Face Trainer) |
| 정확도 검증 | 테스트셋으로 평가, Vision AI와 비교 |

### Week 2: 전환 + 배포

| 할 일 | 설명 |
|---|---|
| 모델 HF Hub 업로드 | Hugging Face에 모델 배포 |
| API Route 전환 | Vision AI → HF 자체 모델 API |
| A/B 테스트 | 기존 Vision AI vs 파인튜닝 모델 비교 |
| 완전 전환 | Vision AI API 비용 제거 |

### 전환 효과

| | 전환 전 (Vision AI) | 전환 후 (자체 모델) |
|---|---|---|
| 비용 | 이미지당 ~$0.01 | 0원 |
| 속도 | 1~3초 | 수십ms |
| 외부 의존 | Anthropic/OpenAI | 없음 |
| 정확도 | 중간 (범용) | 높음 (헤어 특화) |
